# Linux Kernel Design Learning Lab

這個 repository 記錄 Linux Kernel Design 的完整學習歷程。課程不以「看完內容」為目標，而是要求每個階段都有可重現的實驗、真實輸出、除錯證據與能力驗收。

## 目前狀態

- 環境：Stage 0 已完成（依學習地圖記錄，實際版本會在入學診斷再次確認）
- 課程：已完成整體課程設計
- 下一步：Phase 0 入學診斷

## 紀錄原則

每次學習或實驗都記錄：

1. 問題與事前預測
2. 環境、命令及程式版本
3. 真實輸出與觀察
4. 推論、錯誤與限制
5. 驗收結果與下一步

程式、文件與實驗紀錄分成小而清楚的 commit，讓學習脈絡能從 Git history 重建。
